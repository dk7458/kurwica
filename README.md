
# Kurwica - ZFS Pool Maintenance Tool

Kurwica is a command-line tool for automating ZFS pool maintenance on Debian systems. It provides features like automated scrubbing, snapshot management, logging, pool cleaning, and monitoring.

## Features

- Automated Scrubbing: Schedule scrubs at different intervals for each pool.
- Snapshot Management: Automate creation of snapshots based on user-defined intervals or events.
- Logging: Record every action taken by the tool with timestamp.
- Pool Cleaning: Automate removal of expired snapshots and dead data.
- Monitoring: Real-time monitoring of pool health status.
